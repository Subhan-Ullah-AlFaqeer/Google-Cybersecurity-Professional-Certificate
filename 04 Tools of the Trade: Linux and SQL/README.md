# 🛡️ Course 4: Tools of the Trade: Linux and SQL

Welcome to **Course 4** of the **Google Cybersecurity Professional Certificate**! This course equips you with foundational computing and data querying skills essential for a security analyst. You will explore computer operating systems, master the Linux operating system architecture and distributions, navigate files and manage user authorization through the Bash shell, and learn how to use Structured Query Language (SQL) to query, filter, and join relational database tables for security log analysis.

---

## 📝 Core Technical Objectives
- **Operating Systems & Hardware Interaction:** Understanding the relationship between hardware, software, and the operating system kernel, and comparing Graphical User Interfaces (GUI) with Command Line Interfaces (CLI).
- **Linux Architecture & Distributions:** Exploring open-source Linux distros (Ubuntu, Debian, Kali Linux), package management (`apt`), and the distinction between user space and kernel space.
- **Bash Shell Administration & File Security:** Executing terminal commands to navigate directory structures, manage files, configure file permissions (`chmod`, `chown`), administer user accounts, and execute tasks with `sudo`.
- **Relational Databases & SQL Querying:** Understanding database schemas, writing basic queries (`SELECT`, `FROM`), filtering telemetry with conditional operators (`WHERE`, `AND`, `OR`, `NOT`), and combining tables using relational joins (`INNER JOIN`, `LEFT JOIN`).

## 🎯 Technical Skills Architecture

### 📊 Linux Administration & File Security
- **Terminal Proficiency:** Navigating directories, manipulating files, and capturing command outputs using Bash redirection operators (`>`, `>>`, `\|`).
- **Authorization & Access Control:** Setting granular file permissions (`chmod`, `chown`) and provisioning user accounts securely.
- **System Troubleshooting:** Querying built-in manual pages (`man`) to independently research syntax and resolve technical blockers.

### 🤖 Applied Practice & Database Querying
- **SQL Log Analysis:** Constructing filtered queries to isolate suspicious login attempts, out-of-hours activity, and targeted IP ranges.
- **Table Correlation:** Writing multi-table `JOIN` queries to link user accounts, host assets, and security event logs.
- **Portfolio Demonstration:** Authoring job-ready documentation of Linux permission hardening and SQL query analyses.
