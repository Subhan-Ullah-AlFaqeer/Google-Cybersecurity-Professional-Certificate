# 🛡️ Course 3: Connect and Protect: Networks and Network Security

Welcome to **Course 3** of the **Google Cybersecurity Professional Certificate**! This course delivers a comprehensive exploration of network architecture, protocols, security operations, intrusion vectors, and system hardening. You will examine network communication models (TCP/IP vs. OSI), analyze common network protocols (DNS, DHCP, HTTP/HTTPS, TLS), implement perimeter defenses (firewalls, VPNs, proxies, DMZs), investigate intrusion tactics like DoS/DDoS attacks and IP spoofing using `tcpdump` log analysis, and execute OS, network, and cloud hardening techniques backed by a NIST Cybersecurity Framework (CSF) incident response portfolio project.

---

## 📝 Core Technical Objectives
- **Network Architecture & Communication Models:** Understanding physical and virtual network topologies, cloud infrastructures (VPCs, SDN), and tracing protocol encapsulation across the 4-layer TCP/IP suite and 7-layer OSI model.
- **Network Operations & Perimeter Controls:** Implementing network-layer protocols, wireless standards (WEP to WPA3), firewalls, VPNs (WireGuard and IPSec), proxy servers, and DMZs while calculating subnets using CIDR notation.
- **Intrusion Mechanics & Packet Forensics:** Analyzing threat vectors including Denial of Service (DoS/DDoS) floods, packet sniffing, IP spoofing, and ARP poisoning through command-line packet capture tools like `tcpdump`.
- **System Hardening & Portfolio Incident Response:** Applying OS, network, and cloud hardening baselines, managing Identity and Access Management (IAM) and cryptography, and executing an end-to-end incident response project using the NIST CSF functions.

## 🎯 Technical Skills Architecture

### 📊 Network Protocol Analysis & Perimeter Security
- **Protocol & Traffic Inspection:** Reading packet-level headers in `tcpdump` to detect SYN floods, spoofed IP addresses, and payload anomalies.
- **Perimeter Engineering:** Designing secure DMZs, selecting stateful firewall rules, and deploying VPN tunnels for encrypted remote access.
- **Subnetting & Addressing:** Utilizing CIDR notation to segment enterprise subnets and limit lateral movement during breaches.

### 🤖 Applied Practice & System Hardening
- **Multi-Layer Hardening:** Disabling unneeded services, configuring account lockout rules, enforcing network access controls, and applying cloud encryption.
- **Incident Response Portfolio Execution:** Documenting incident findings, containment procedures, and post-breach recovery steps aligned with the NIST CSF functions (Identify, Protect, Detect, Respond, Recover).
- **Vulnerability Remediation:** Performing system audits to identify misconfigurations and enforce security baselines across physical and virtual assets.
