# 🛡️ Course 3, Module 4: Security Hardening

Welcome to **Module 4** (the final module) of **Connect and Protect: Networks and Network Security** (Course 3 of the Google Cybersecurity Professional Certificate)! This module provides an operational dive into defense-in-depth strategies, system hardening, and proactive risk reduction across operating systems, networks, and cloud environments. You will explore OS hardening techniques to prevent brute-force attacks, implement network security hardening controls, manage cloud security and cryptographic protection, and complete a high-impact portfolio activity using the NIST Cybersecurity Framework (CSF) to document an end-to-end incident response process.

---

## 📝 Core Technical Objectives
- **Operating System Hardening:** Securing OS configurations by disabling unused services/ports, enforcing strict password policies, applying routine patches, and mitigating brute-force authentication attacks.
- **Network Hardening Strategies:** Implementing network security measures including MAC filtering, disabling unused network protocols, closing open ports, enforcing network access control (NAC), and configuring secure baselines.
- **Cloud Hardening & Cryptography:** Managing security challenges unique to cloud infrastructures, implementing Identity and Access Management (IAM), and leveraging cryptographic protocols to protect data at rest, in transit, and in use.
- **NIST CSF Incident Response Portfolio Project:** Applying the NIST Cybersecurity Framework (Identify, Protect, Detect, Respond, Recover) to analyze, contain, and document a real-world security breach.

## 🎯 Technical Skills Architecture

### 📊 System Hardening & Defense Engineering
- **OS & Network Hardening:** Minimizing attack surfaces by disabling default accounts, closing unused ports, and enforcing least privilege.
- **Cloud Risk Mitigation:** Applying Identity and Access Management (IAM) policies, cloud boundary security, and data encryption.
- **Cryptographic Control:** Utilizing asymmetric/symmetric encryption and TLS protocols to safeguard data lifecycle states.

### 🤖 Applied Practice & Professional Readiness
- **NIST CSF Application:** Utilizing the NIST Cybersecurity Framework to structure incident response documentation and risk reporting.
- **Vulnerability Remediation:** Addressing baseline drift and unpatched software flaws identified during system audits.
- **Portfolio Demonstration:** Publishing a structured incident response document that proves practical security capabilities to hiring managers.
