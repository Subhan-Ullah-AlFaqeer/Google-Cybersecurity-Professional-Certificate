# 🛡️ Course 6: Sound the Alarm: Detection and Response

Welcome to **Course 6** of the **Google Cybersecurity Professional Certificate**! This course focuses on the core practices of incident detection, network traffic monitoring, forensic investigation, and threat response within a Security Operations Center (SOC). You will master the NIST Incident Response (IR) lifecycle (SP 800-61 Rev. 2), capture and analyze network packet traffic (`tcpdump`, Wireshark), investigate Indicators of Compromise (IoCs) using threat intelligence tools (VirusTotal), maintain chain of custody documentation, write and inspect Intrusion Detection System (IDS) rules (Suricata), and query enterprise SIEM logs using Splunk (SPL) and Google SecOps (Chronicle).

---

## 📝 Core Technical Objectives
- **Incident Response Lifecycle & Operations:** Executing the four phases of the NIST SP 800-61 Rev. 2 lifecycle (Preparation, Detection & Analysis, Containment/Eradication/Recovery, Post-Incident Activity) and organizing CSIRT roles and Incident Handler's Journal entries.
- **Network Telemetry & Packet Analysis:** Baselining network traffic flows, inspecting IP/TCP packet headers, detecting data exfiltration, and writing targeted filtering expressions in `tcpdump` and Wireshark.
- **Forensic Artifact Analysis & Threat Intelligence:** Analyzing file hashes (MD5, SHA-256) on VirusTotal, maintaining chain of custody documentation, executing incident response playbooks, performing alert triage, and reconstructing event chronologies.
- **Intrusion Detection & SIEM Querying:** Customizing Suricata IDS signature rules (`eve.json`, `fast.log`), parsing security alerts, executing SPL queries in Splunk, and navigating Unified Data Models (UDM) in Google SecOps (Chronicle).

## 🎯 Technical Skills Architecture

### 📊 Network Forensics & Incident Response
- **Packet Mechanics:** Decoding Ethernet frames, IP headers, TCP flags (SYN, ACK, FIN, RST), and payload bytes to pinpoint malicious traffic.
- **Threat Intelligence Triage:** Querying file hashes on VirusTotal to identify malware families and extract associated IoCs.
- **SIEM & IDS Querying:** Crafting Suricata rules and authoring Splunk SPL search statements (`stats count by clientip`) to filter incident logs.

### 🤖 Applied Practice & Professional Readiness
- **Incident Journaling:** Documenting chronological event logs, evidence hashes, and containment decisions in a professional journal.
- **Playbook Execution:** Navigating step-by-step incident response procedures to contain phishing attacks and network breaches rapidly.
- **Post-Incident Reporting:** Reconstructing accurate timelines and drafting final incident reports to strengthen organizational posture.
