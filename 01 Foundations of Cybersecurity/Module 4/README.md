# 🛡️ Course 1, Module 4: Cybersecurity Tools and Programming Languages

Welcome to **Module 4** (the final module) of **Foundations of Cybersecurity** (Course 1 of the Google Cybersecurity Professional Certificate)! This module provides an operational overview of the primary software tools and programming languages used by security analysts to defend business operations, detect threats, and analyze logs. You will explore Security Information and Event Management (SIEM) tools, network protocol analyzers (packet sniffers), operating systems like Linux, and programming languages such as SQL and Python. Additionally, you will craft a professional statement to launch your cybersecurity portfolio.

---

## 📝 Core Technical Objectives
- **SIEM & Security Operations Tools:** Understanding how Security Information and Event Management (SIEM) systems aggregate, correlate, and analyze log data across enterprise networks to alert analysts to potential security incidents.
- **Packet Analysis & Network Security:** Exploring network protocol analyzers (e.g., Wireshark, tcpdump) to capture and inspect data packets traversing organizational network boundaries.
- **Linux, SQL, and Python Fundamentals:** Recognizing the operational role of Linux command-line tools for system administration, SQL for database log querying, and Python for automating security tasks and scripts.
- **Portfolio Readiness:** Drafting a concise, high-impact professional statement that summarizes technical strengths, career goals, and security focus areas for prospective employers.

## 🎯 Technical Skills Architecture

### 📊 Security Tooling & Infrastructure
- **SIEM Management:** Understanding event logging, correlation rules, and alert triage processes within Security Operations Centers (SOCs).
- **Network Inspection:** Analyzing packet-level data to identify unencrypted traffic, abnormal spikes, or unauthorized connections.
- **Scripting & Queries:** Recognizing how SQL queries extract threat indicators from database logs and how Python scripts automate routine tasks.

### 🤖 Applied Practice & Professional Readiness
- **Portfolio Development:** Structuring a professional portfolio showcasing projects, scripts, and security certifications.
- **Professional Branding:** Writing a clear professional statement articulating entry-level capabilities and technical focus.
- **Interactive Triage:** Engaging in simulated analyst dialogues to practice incident response reasoning and tool selection.
