# 🛡️ Course 5: Assets, Threats, and Vulnerabilities

Welcome to **Course 5** of the **Google Cybersecurity Professional Certificate**! This course delivers a comprehensive exploration of organizational asset protection, risk management, cryptography, identity and access management, vulnerability management, and proactive threat modeling. You will examine asset classification models, apply NIST Cybersecurity Framework (CSF) guidelines, evaluate data across its lifecycle states, implement IAM and AAA controls, analyze vulnerabilities using CVE/MITRE standards, adopt an attacker mindset to evaluate entry points, and master structured threat modeling using the PASTA framework.

---

## 📝 Core Technical Objectives
- **Asset Classification & Risk Governance:** Establishing data and asset classification schemas, evaluating data in its three states (rest, transit, use), and performing quantitative risk scoring using likelihood and severity metrics within NIST CSF guidelines.
- **Cryptography & Access Control (AAA):** Differentiating between symmetric/asymmetric encryption, applying Public Key Infrastructure (PKI), ensuring data integrity with cryptographic hashing (SHA-256), and designing Identity and Access Management (IAM) systems using Multi-Factor Authentication (MFA), Single Sign-On (SSO), and Role-Based Access Control (RBAC).
- **Vulnerability Management & Attacker Mindset:** Tracking flaws via MITRE CVE IDs, analyzing the OWASP Top 10, conducting vulnerability scans and penetration tests, and adopting a threat actor perspective to identify attack vectors (e.g., rogue USBs, brute-force attacks).
- **Threat Identification & Threat Modeling:** Dissecting social engineering tactics (phishing, smishing, vishing), malware families (ransomware, trojans, cryptojacking), web exploits (XSS, SQL Injection), and executing the 7-stage PASTA threat modeling framework.

## 🎯 Technical Skills Architecture

### 📊 Cryptography, Access Control & Governance
- **Data Lifecycle Protection:** Recommending tailored cryptographic algorithms (symmetric vs. asymmetric) and access boundaries for sensitive data states.
- **IAM Architecture:** Configuring Multi-Factor Authentication (MFA) and Single Sign-On (SSO) alongside fine-grained authorization policies.
- **Risk Calculation:** Evaluating risk exposure scores by multiplying threat likelihood ratings by impact severity levels.

### 🤖 Applied Practice & Threat Analysis
- **Vulnerability Audit & Remediation:** Mapping software flaws against MITRE CVE registries and executing systematic vulnerability assessments.
- **Attack Surface Analysis:** Dissecting web application exploits (XSS, SQLi) and implementing parameterized queries and input sanitization.
- **PASTA Threat Modeling:** Applying all 7 stages of the Process for Attack Simulation and Threat Analysis (PASTA) to simulate real-world attack scenarios and guide SOC defensive posture.
