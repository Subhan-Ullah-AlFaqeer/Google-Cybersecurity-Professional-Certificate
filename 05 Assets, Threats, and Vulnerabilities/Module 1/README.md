# 🛡️ Course 5, Module 1: Introduction to Asset Security

Welcome to **Module 1** of **Assets, Threats, and Vulnerabilities** (Course 5 of the Google Cybersecurity Professional Certificate)! This opening module explores asset security, risk management, and security governance frameworks. You will examine the methodologies organizations use to inventory, classify, and protect physical and digital assets, analyze data across its three operational states, apply the NIST Cybersecurity Framework (CSF), and perform risk scoring based on threat likelihood and impact severity.

---

## 📝 Core Technical Objectives
- **Asset Classification & Handling:** Establishing data and physical asset classification schemas (e.g., Public, Internal, Confidential, Restricted) to align security controls with business value and regulatory requirements.
- **Data States in the Workplace:** Protecting assets across all three states of the data lifecycle:
  - **Data at Rest:** Inactive data stored in databases, hard drives, or cloud storage (secured via AES encryption and access controls).
  - **Data in Transit:** Active data moving across network connections (secured via TLS, SSH, and VPN tunneling).
  - **Data in Use:** Data actively being accessed or processed in RAM/CPU memory (secured via least privilege and endpoint protection).
- **Risk Scoring & Assessment Mechanics:** Evaluating organizational risks by calculating likelihood and impact severity scores to prioritize security investments and mitigation workflows.
- **NIST Framework Standards:** Integrating NIST standards, guidelines, and best practices to structure enterprise security plans and risk management operations.

## 💡 Visual Pipeline Reference

The risk evaluation formula and data state protection model governing Module 1:

- **Risk Scoring & Matrix Calculation**:

$$\text{Risk Exposure Score} = \text{Likelihood Rating (1--5)} \times \text{Impact Severity Rating (1--5)}$$

- **Data Lifecycle States & Security Controls Taxonomy**:

| Data State | Operational Context | Primary Defensive Mechanisms |
| :--- | :--- | :--- |
| **Data at Rest** | Stored on SSDs, databases, backup media, cloud buckets | Full Disk Encryption (FDE), AES-256, access control lists (ACLs) |
| **Data in Transit** | Transmitting across Wi-Fi, Ethernet, internet connections | HTTPS/TLS 1.3, WireGuard/IPsec VPNs, SSH, WPA3 enterprise |
| **Data in Use** | Temporarily stored in RAM, CPU cache, or volatile memory | Identity and Access Management (IAM), Least Privilege, Secure Enclaves |

## 🎯 Technical Skills Architecture

### 📊 Asset Management & Risk Governance
- **Asset Classification:** Categorizing physical devices, cloud resources, and intellectual property to establish proper access baselines.
- **Risk Assessment:** Performing quantitative and qualitative risk scoring to identify critical vulnerabilities requiring immediate patching.
- **Framework Application:** Utilizing NIST guidelines to design comprehensive organizational security plans.

### 🤖 Applied Practice & Professional Readiness
- **Data Lifecycle Protection:** Recommending encryption and access controls tailored to specific data states (rest, transit, use).
- **Physical & Digital Safeguards:** Balancing physical security controls (badge access, locks) with logical controls (firewalls, IAM).
- **Threat Mitigation Prioritization:** Translating likelihood and impact matrix calculations into actionable SOC mitigation tickets.
