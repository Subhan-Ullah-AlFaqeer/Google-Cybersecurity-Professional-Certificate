# 🛡️ Course 5, Module 3: Vulnerabilities in Systems

Welcome to **Module 3** of **Assets, Threats, and Vulnerabilities** (Course 5 of the Google Cybersecurity Professional Certificate)! This module provides a detailed exploration of vulnerability management, defense-in-depth strategies, and threat actor tactics. You will examine the Common Vulnerabilities and Exposures (CVE) system, the OWASP Top 10 web application security risks, Open Source Intelligence (OSINT), CI/CD pipeline vulnerabilities, vulnerability scanning and penetration testing methodologies, and adopt an attacker mindset to identify physical and logical attack vectors (including USB drop attacks and brute-force mitigations).

---

## 📝 Core Technical Objectives
- **Vulnerability Management & CVE Framework:** Understanding the continuous vulnerability management lifecycle, tracking known flaws via Common Vulnerabilities and Exposures (CVE) IDs, and evaluating CI/CD software pipeline security risks.
- **OWASP Top 10 & OSINT Analysis:** Identifying top web application vulnerabilities (e.g., Broken Access Control, Injection flaws, Cryptographic Failures) and utilizing Open Source Intelligence (OSINT) to assess public asset exposure.
- **Vulnerability Assessments & Penetration Testing:** Differentiating between automated vulnerability scanning (internal vs. external, credentialed vs. non-credentialed) and manual penetration testing to evaluate defense-in-depth postures.
- **Attacker Mindset & Attack Vector Triage:** Adopting threat actor perspectives to map physical/logical entry points, analyze attack vectors (such as unauthorized USB devices and brute-force authentication attacks), and complete a vulnerable system portfolio analysis.

## 🎯 Technical Skills Architecture

### 📊 Vulnerability Analysis & Scanning
- **CVE Identification:** Referencing CVE registries and CVSS metrics to classify software flaw severity.
- **Scanning Selection:** Choosing credentialed scans for thorough internal patch audits versus non-credentialed scans for external perimeter views.
- **Application Security Assessment:** Aligning web security reviews with OWASP Top 10 categories to catch access control and injection risks.

### 🤖 Applied Practice & Professional Readiness
- **Attacker Mindset Application:** Mapping physical and logical pathways threat actors take to bypass perimeter security.
- **Physical Attack Vector Mitigation:** Establishing endpoint policies (e.g., USB port disabling, autorun restrictions) to block hardware intrusion vectors.
- **Portfolio Demonstration:** Publishing a structured vulnerability audit report detailing target weaknesses and actionable remediation recommendations.
