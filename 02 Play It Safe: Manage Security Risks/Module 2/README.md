# 🛡️ Course 2, Module 2: Security Frameworks and Controls

Welcome to **Module 2** of **Play It Safe: Manage Security Risks** (Course 2 of the Google Cybersecurity Professional Certificate)! This module explores security frameworks, technical/administrative controls, and governance structures. You will investigate the core components of the CIA triad, analyze the six core functions of the NIST Cybersecurity Framework (CSF 2.0), implement OWASP security principles, and plan and execute an enterprise security audit as part of your hands-on portfolio.

---

## 📝 Core Technical Objectives
- **Frameworks & Controls Synergy:** Understanding how security frameworks (blueprints) guide the selection and implementation of specific administrative, technical, and physical security controls (safeguards).
- **Practical Application of the CIA Triad:** Analyzing workplace security scenarios through Confidentiality, Integrity, and Availability to ensure complete asset protection.
- **NIST Cybersecurity Framework Functions:** Mastering the six core functions of the NIST CSF framework: **Govern, Identify, Protect, Detect, Respond, and Recover**.
- **OWASP Principles & Security Auditing:** Applying Open Worldwide Application Security Project® (OWASP) secure design principles and conducting structured security audits to evaluate internal compliance and risk posture.

## 🎯 Technical Skills Architecture

### 📊 Framework Governance & Auditing
- **NIST CSF Execution:** Aligning organizational security posture with the NIST core functions (Govern through Recover).
- **Security Audit Methodology:** Assessing compliance gaps, auditing existing controls, and documenting risk recommendations.
- **OWASP Secure Design:** Implementing principles such as least privilege, defense-in-depth, and secure defaults.

### 🤖 Applied Practice & Professional Readiness
- **Control Evaluation:** Inspecting system environments to verify that administrative, technical, and physical controls operate effectively.
- **Portfolio Documentation:** Authoring formal security audit reports that articulate risk findings to organizational leadership.
- **Threat Vector Mitigation:** Mapping control failures to CIA triad breaches to justify security investments.
