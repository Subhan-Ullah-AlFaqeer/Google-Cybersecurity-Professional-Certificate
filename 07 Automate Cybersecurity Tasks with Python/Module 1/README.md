# 🛡️ Course 7, Module 1: Introduction to Python

Welcome to **Module 1** of **Automate Cybersecurity Tasks with Python** (Course 7 of the Google Cybersecurity Professional Certificate)! This module launches your journey into automating security workflows using Python. You will explore how security analysts leverage scripting to streamline log parsing, access control validation, and security auditing. You will master core Python concepts including data types, variable assignments and reassignments, conditional logic (`if`, `elif`, `else`), and iterative control structures (`for` and `while` loops).

---

## 📝 Core Technical Objectives
- **Python in Cybersecurity Automation:** Understanding the role of Python in automating repetitive security operations, log triage, IP parsing, and network monitoring.
- **Data Types & Variable Assignment:** Working with foundational Python data types—Strings (`str`), Integers (`int`), Floats (`float`), and Booleans (`bool`)—and managing dynamic variable creation and reassignment.
- **Conditional Logic Execution:** Implementing `if`, `elif`, and `else` statements along with logical operators (`and`, `or`, `not`) and comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`) to enforce security access logic.
- **Iterative Control Structures:** Constructing `for` loops to iterate over data sequences (e.g., lists of IP addresses or log records) and `while` loops to execute tasks until specific security criteria are met.
